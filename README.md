# Onder Papírbolt - Tiszaújváros

Ez a projekt a tiszaújvárosi Onder Papírbolt hivatalos weboldalának forráskódját tartalmazza.

## A projektről
A weboldal célja, hogy a vásárlók könnyen tájékozódhassanak az üzlet kínálatáról, szolgáltatásairól és elérhetőségeiről.

### Főbb funkciók:
- **Kezdőlap**: Általános információk, bemutatkozás és kiemelt ajánlatok.
- **Szolgáltatások**: Részletes tájékoztatás a nyomtatási, fénymásolási és egyéb irodai szolgáltatásokról.
- **Újság**: Az aktuális termékkatalógus és akciók böngészése.
- **Kapcsolat**: Nyitvatartás, térkép és elérhetőségi adatok.

A projekt React és Vite segítségével készült, modern és reszponzív megjelenést biztosítva.
